# Test Automation Challenges
## General requirements:
- Select Challenge 1 or Challenge 2, or both
- Create 2 or more scenarios per challenge using any test automation framework (Cypress, Playwright, Selenium, CodeceptJS, TestCafe, etc.)
- The scenarios should cover key user flows and include intent of the test case, any pre-conditions, explicit test steps with clear expected results, and error handling
- Implement challenges in a newly created public Git repository
- The challenges will be reviewed during technical portion of the in-person interview

## Challenge 1:
UI Test Automation. Create and automate test scenarios for the website
https://www.demoblaze.com.

## Challenge 2:
API Test Automation. Create and automate test scenarios for APIs from https://thinking-
tester-contact-list.herokuapp.com/. Create simple CRUD operations.
